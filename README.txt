NEON ORBIT - build com ajustes de upgrades, Speed of Light e áudio

Arquivos:
- index.html
- style.css
- script.js
- server.js
- package.json

Alterações desta versão:
- Corrigida a seleção de upgrades nos níveis múltiplos de 5: a tela não é descartada quando o último orbe da fase também provoca o level-up.
- Contador de pontos coletados no HUD.
- Speed of Light mostra pontos acumulados como esferas douradas brilhantes em órbita durante a carga de 3 segundos.
- As esferas convergem para o jogador antes das investidas.
- Cinco investidas rápidas, rastro arco-íris, efeito visual de tempo congelado e atração dos orbes da arena.
- Música de rock original sintetizada pelo Web Audio, efeito sonoro ao coletar orbes e pequena fanfarra de level-up.
- Mantidos os controles mobile por dispositivo da versão anterior.

Observação de áudio:
O navegador exige uma interação do usuário para liberar o áudio. Inicie a partida após tocar/clicar na tela e confira se o botão de áudio está ligado e se o volume do dispositivo não está mudo.

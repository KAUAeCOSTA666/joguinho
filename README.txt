NEON ORBIT — MULTIPLAYER ONLINE

Arquivos: index.html, style.css, script.js para GitHub Pages; server.js e package.json para o serviço Node no Render.

1) Envie index.html, style.css e script.js para a raiz do repositório GitHub Pages.
2) Envie server.js e package.json para a raiz do repositório conectado ao Render (pode ser o mesmo repositório).
3) No Render, serviço Web Service, comando de build: npm install; comando de start: npm start.
4) Aguarde o deploy e abra a página do jogo em dois navegadores/dispositivos. Um cria a sala e o outro entra com o código.

O endereço do servidor está configurado em script.js como https://joguinho-ma2q.onrender.com. Se o serviço Render tiver outro endereço, atualize ONLINE_SERVER_URL.
